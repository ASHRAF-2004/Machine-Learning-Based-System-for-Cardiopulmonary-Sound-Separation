## Primary-source product references

- [Linear, A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh),
  March2026: task content outranks orientation; compact controls and predictable
  header actions; pruning duplicated borders/pages. Adopt density discipline,
  not Linear's dark palette, proprietary assets or exact layout.
- [Linear, personalized sidebar and settings](https://linear.app/changelog/2024-12-18-personalized-sidebar):
  familiar grouping for personal settings and account controls. Use six sections
  rather than one giant form.
- [Apple Human Interface Guidelines, materials](https://developer.apple.com/design/human-interface-guidelines/materials):
  use translucency as hierarchy/navigation material while ensuring legibility.
  Public documentation currently requires browser JavaScript; search excerpt
  consulted, not a claim that an Apple reference app was tested.
- [Ableton Live12 audio-effect reference](https://www.ableton.com/en/manual/live-audio-effect-reference/):
  audio tools expose waveform/spectrum information with axes and familiar
  playback controls. Borrow measurement clarity, not a dense DAW cockpit.
